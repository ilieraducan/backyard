Use a Generator Safely

A generator keeps the freezer and furnace fan running in a winter outage, but carbon monoxide is deadly and invisible. Follow these rules every time.

The full list

  1. Run it outdoors only
  2. 20+ ft from doors, windows
  3. Never in a garage
  4. Install CO alarms inside
  5. Cool before refueling
  6. Use outdoor-rated cords
  7. Never backfeed a wall outlet
